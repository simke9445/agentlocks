# Code Of Conduct

Agentlocks is built for precise, collaborative engineering work. Project spaces should stay useful
for maintainers, contributors, and users trying to debug real problems.

## Expected Behavior

- Be direct, technical, and respectful.
- Critique code, claims, and tradeoffs rather than people.
- Include enough context for others to reproduce bugs or evaluate proposals.
- Keep security-sensitive details out of public issues and follow `SECURITY.md`.

## Unacceptable Behavior

- Harassment, threats, hate speech, or personal attacks.
- Repeated off-topic posting after a maintainer asks to refocus.
- Publishing private information, credentials, exploit details, or local paths that do not belong in
  a public thread.
- Deliberately disruptive behavior that makes the project harder to maintain.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; block users; or restrict repository
access when behavior harms the project or its participants. Enforcement decisions prioritize keeping
the repository safe, technical, and productive.

To report conduct concerns, use the maintainer contact path in `SECURITY.md` if private details are
involved, or open a GitHub issue if the concern is safe to discuss publicly.
